Grok NCL v7 手機GPU實測

只需按一下。頁面會自動：驗證檔案 → 安裝離線快取 → 載入真實模型 → GPU對照參考答案 → 短測 → 正式30輪，最後顯示結果並可下載JSON。

    這是已訓練的70,048參數v7 compat小模型（byte模型），不是70B。GPU（WebGPU）負責全部推論與採樣；CPU（JavaScript）只負責讀檔、驗證、提交、計時與匯出。沒有WebGPU會直接失敗，不會改用CPU。頁面不連任何外部網址。記憶體RSS瀏覽器無法取得，標為NOT VERIFIED。

    斷網（飛航模式）測試

    第一次按「開始測試」成功後，開飛航模式並關Wi-Fi，重新整理本頁，勾選下方，再按一次「開始測試」，然後按「檢查離線證據」。
