# 國家財稅資料與審計引擎

**範圍：** 純資料處理 JavaScript 模組；不含 DOM、網路抓取、資料庫寫入、SQL migration、主頁 HTML 或 AI API。

## 能力
- 將政府公開資料欄位映射為統一財政紀錄，保留來源、發布時間、原始單位。
- 計算預算與實徵差額、差異率及執行率。
- 依稅目、年度、機關及地區進行分組比較。
- 使用同口徑歷史樣本的 median/MAD robust deviation 偵測統計異常。
- 產生 0–100 預警排序分數，並明確標示非違法認定。
- 將「統計異常」「待查核線索」「人工確認」分為不同狀態；人工確認只能由授權人員的獨立流程設定，本模組不會自行確認。

## 執行測試
在支援 Node.js 18+ 的環境：
```sh
node --test modules/national-fiscal-audit/tests/engine.test.mjs
```

本分支尚未接入前端或正式資料來源。Fixture 全部為合成數據，不代表政府實際統計。

## 第一批官方資料來源（待下載、欄位核對及版本封存）
1. 財政部：全國賦稅收入實徵淨額與預算數之比較（政府資料開放平臺 dataset 16910）  
   https://data.gov.tw/dataset/16910
2. 財政部：全國賦稅收入實徵淨額日曆年別－按稅目別與機關別分（dataset 6741）  
   https://data.gov.tw/dataset/6741
3. 財政部賦稅署：近10年營業稅預算數及實徵數（dataset 46025）  
   https://data.gov.tw/dataset/46025
4. 行政院主計總處：各直轄市及縣市總預算彙編（dataset 10887）  
   https://data.gov.tw/dataset/10887
5. 財政部：每月賦稅收入統計及按政府別附表  
   https://www.mof.gov.tw/

來源授權、更新日期、單位、修訂版次及統計口徑必須隨每次匯入保存。不同年度若稅制、統籌分配或政府別歸屬改變，應標註制度斷點，不可直接把名目變動解讀為績效變動。

## 重要方法限制
- 不同單位、不同政府別、不同會計基礎不可直接相加。
- 年度預算、累計分配預算、法定預算、決算數及實徵數不是同一概念。
- 年度未結束時，累計實徵不可直接與全年預算比較；應採同期間分配預算或同期歷史資料。
- 統計異常只產生待查線索。需排除法規變更、景氣循環、一次性收入、稅收歸屬改變、資料缺漏及修訂後，才可由人工覆核。
