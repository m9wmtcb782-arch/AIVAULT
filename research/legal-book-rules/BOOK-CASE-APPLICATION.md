# 第七段：題目事實到書中規則的完整對照

2026-10-19；基於3936fb9b1416d1f162b4cd68ea4a3b59ae716533。

## 這次新增的實際能力

`book-case.cjs`接收問題及題目事實原文，按已核對的事實語法抽取TRUE／FALSE，保存每個判斷在題目中的原文起訖位置；再以書中已核對規則判斷條件、例外與結論。`solve.cjs`提供同一個入口，路由到概念、理由、原文或案例對照；不呼叫外部模型，失敗時也不偷偷切換供應商。

同一事實的肯定與否定不能同時使用；互斥分類同時成立時回報矛盾。未提到的事實是UNKNOWN。問句、引述、可能、如果、例外未明與未解析子句不能丟掉後當成確定前提。組織身分與活動分類分開，不因「不是國家機關」就推定「屬於公行政」。

這是受限事實語法，不是完整自然語言理解。仍不能從任意敘事自行判斷活動的法律性質。未解析子句會要求檢查，並非默認無影響。

## 真實教材與假設案例

依已核對的姜明安第八版PDF51–52頁，使用書中「行政法學研究對象為公行政、而非私行政」的概念界定，建立兩條對照規則。資料保存在私有`AIVAULT-book-case-001.json`；不把書頁全文推入程式庫。

規則只用於本書研究範圍的理論分類。來源的法域與法規時間尚未核實，不能因此套用現行法、判定合法性、訴訟資格或法院管轄。沒有修改原本對實際法律規則的法域／時間檢查；本模組是明示隔離的書中概念假設適用。

示例題目：本案組織不是國家行政機關；本案活動屬於公行政。依本書，活動是否在行政法學研究範圍？

程式回答包含：依本書可納入；理由是活動已被題目明示為公行政，研究範圍不限國家機關；附上原文、題目原句與PDF51–52頁。組織身分雖被記錄，但不單獨作為活動分類或結論的充分條件。

口語說明使用來源核對過的規則解釋與固定段落模板；不在作答時呼叫模型潤飾。解釋文字屬資料卡審核範圍，修改後須更新核對指紋；原文引文獨立保存、不刪否定與標點。

## 驗證與解題目標

工程測試由141增加為167：22個事實／案例回歸測試、4個統一入口測試，全部通過。測試中的一般例外規則為合成文本，不冒稱教材上的具體法律例外。

另以真實教材為依據，建立8個假設對照案例，預期處理由本次助手依原文設定：

| 題目變化 | 程式結果 |
|---|---|
| 非國家組織＋明示公行政 | 得出本書研究範圍內的結論 |
| 國家組織＋明示私行政 | 得出本書研究範圍外的結論 |
| 只有非國家組織身分 | 缺活動分類，要求補充 |
| 只有不是私行政 | 不反推必為公行政 |
| 公行政性質仍是疑問 | 要求核對事實，不當成肯定 |
| 公行政、私行政同時宣稱成立 | 回報矛盾 |
| 另有未解析特殊規定 | 要求核對，不忽略限制 |
| 簡體明示公行政 | 得出本書研究範圍內的結論 |

8/8符合預期行為，其中只有3題產生實質結論；其餘5題為需要事實、語意核對或矛盾處理。不能把8/8說成答對8題完整法律案例。這是開發者對照，不是獨立專家盲評。

執行`node research/legal-book-rules/test/audit-cases.cjs <私有案例知識包.json>`可重現路由、結論及缺失事實的結果。原概念與理由測試亦可重用此包中的對應欄位。

## 2026-10-19：相反規則尚未釐清時不得提前結論

新增檢查發現：某條充分規則成立時，舊流程會忽略另一條相反規則的 UNKNOWN 前提或例外，過早輸出單一答案。修正為檢查所有尚未確定且指向同一結論鍵、相反極性的規則；仍可能成立時回傳 NEEDS_FACTS、缺少的事實鍵及 pendingRuleIds，不輸出 conclusion。

已核對的 exclusiveGroups 可用於排除相反規則的可能性。這是已知事實加上卡片互斥約束的推導，不是題目明示事實；不寫回 facts.values，也不憑否定一類就肯定另一類。排除過程保留於 trace.excludedCompetingRules。相同方向的未決規則不妨礙一條已成立的充分規則；兩條已成立且結論相反的規則仍回傳 MULTIPLE_VIEWS。

新增 8 項合成案例測試，其中核心案例先重現舊版過早結論，再修正；涵蓋未知反方前提、明示否定、互斥排除、已成立衝突、同方向規則、未知反方例外、已成立例外、不得由兩個否定推出肯定。完整工程測試 194/194。原教材 21 案例行為維持預期：8 題有實質結論、13 題未決或矛盾；概念 12 題及理由 3 題回歸通過。這些是開發者自訂測試與回歸，並非獨立專家盲測、真實法律正確率或與大型模型能力相當的證據。

此變更僅限研究分支的 Node 模組。尚未接入正式頁面、驗證 iPhone Safari，也未呼叫模型或付費 API。
