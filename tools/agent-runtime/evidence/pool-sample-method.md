# 正式名冊抽樣的本機替代驗收

2026-11-09。唯讀從正式名冊選取十個已存在的 ID。依衍生狀態與路由供應商分層，以 ID 加固定字串 `aivault-alternate-20261109` 的 MD5 排序選取前幾筆，分別取 6 個 Gemini 衍生身分、2 個 Gemini 原始身分、2 個 Groq 原始身分。公開證據保存身分 ID 的 SHA-256。

在隔離 Linux 容器，使用已核對 GGUF SHA-256 的 Qwen2.5 1.5B 與既有本機 bridge。每個身分各跑一次，由模型選 MAX 或 MIN，工具執行後再由模型回報結果。共 20 次模型推論、50 個生成 token，9/10 完整通過。一次要求取 74 和 31 中較大值，模型卻選 MIN 並回報 31，判定失敗。衍生身分 6/6，原始身分 3/4。名冊路由是抽樣欄位，推論統一走本機 Qwen。這項測試沒有經過正式執行器或驗證正式推論權限。
