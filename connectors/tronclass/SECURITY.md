# SECURITY — TronClass Connector

與施工令對齊的**明確禁止**：

1. **禁止**未確認學校授權前啟用自動登入或背景抓取。  
2. **禁止**儲存明文學號／密碼（程式、設定、log、記憶體持久層）。  
3. **禁止**繞過驗證碼或任何登入保護（含 OCR 打正式登入）。  
4. **禁止**使用付費 API。  
5. **禁止**將教材同步結果公開至 GitHub Pages 或正式公開站。  
6. **禁止**修改 TronClass 上任何資料（唯讀）。  
7. **禁止**將未審核第三方（如 tronclass-api）投入正式環境。  
8. **禁止**繞過教師「不可下載」限制或利用預覽 URL 漏洞。  
9. **禁止**以模擬／假資料宣稱「真實同步成功」。  
10. **禁止**影響既有正式服務／正式頁面之行為作為本功能副作用。  

撤銷：呼叫 `auth.revoke()`，關閉排程 `scheduler.enabled=false`，並清除本機 opaque credential ref。
