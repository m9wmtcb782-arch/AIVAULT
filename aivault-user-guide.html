AIVAULT 使用說明

本說明以目前 AIVAULT 網站的工作流程為準，目的是讓使用者知道「從哪裡進入、要做什麼、發生問題時怎麼判斷」，而不是單純列出按鈕。

AIVAULT 工作中心Technical Dark Star 暗星電子書教學助理協作池算力池

一、第一次使用

  1. 從 AIVAULT Home 進入需要的工作模組。
  2. 需要法律教材時進入「電子書／數位書架」。
  3. 需要 AI 研究、分析或工作協作時進入 Technical Dark Star。
  4. 需要課程與學習操作時進入教學助理。
  5. 需要跨 AI 協作或算力資源時進入協作池／算力池。
如果某個頁面載入失敗，先確認網址、網路與瀏覽器重新整理；不要因為單一模組失敗就重建整個 AIVAULT。

二、Technical Dark Star 暗星

  • 暗星是 AIVAULT 的 Technical Dark Star 工作代理，不等同於 Gemini、Groq 或其他 Provider。
  • 可以用文字、語音等方式提出問題；回答應以目前工作內容與可取得的上下文為依據。
  • 在法律教材中，可由「問暗星」針對目前頁面、章節或指定頁面提問。
  • 若需要連續討論，應保留同一工作主題與上下文，避免把新問題誤當成新的工作。

三、AIVAULT 電子書／數位書架

書架提供「我的書架、最近閱讀、我的收藏、最近新增、我的分類、搜尋」等入口。

閱讀

  • 點擊書籍進入閱讀模式。
  • 手機可使用單頁閱讀；桌面環境可使用雙頁閱讀，也可在閱讀設定中切換。
  • 可用上一頁／下一頁、頁碼滑桿與觸控滑動移動。
  • 閱讀進度會保存，重新進入同一本書時可繼續閱讀。

閱讀工具

  • ☰ 目錄：依教材章節定位。
  • 🔖 書籤：保存重要頁面。
  • 🔍 搜尋：搜尋全書文字內容。
  • 📝 筆記：保存頁面筆記。
  • 🔊 朗讀：朗讀目前頁、目前章或指定頁碼範圍。
  • 🤖 問暗星：把目前電子書上下文交給暗星解說。
  • ⚙ 閱讀設定：單頁／雙頁、縮放、適合頁面／寬度、收藏與分類。

四、電子書匯入

書架目前支援透過瀏覽器匯入常見教材格式，包括：

PDFWordPPTExcelJPG／PNG／WebPTXT／Markdown

匯入後先建立本機閱讀資料；若內容符合後端匯入條件，再進入既有電子書教材資料層。不要把「本機閱讀建立成功」與「後端教材發布成功」混為同一件事。

五、目前書架法律教材

《中華人民共和國憲法｜現行2018修正｜繁體逐條解讀》

本教材提供 2018 年修正文本的學習性逐條說明，並設有「官方全文／逐條解讀」閱讀入口。正式法律研究、引用或判斷時，應以官方公布文本核對；逐條解讀屬學習輔助，不取代正式法律解釋。

六、教學助理

  • 用於課程閱讀、教材理解、朗讀與學習輔助。
  • 遇到長文可先指定「從哪一段／哪一頁開始，到哪一段／哪一頁停止」。
  • 若使用語音，先確認瀏覽器麥克風權限及輸入語言設定。

七、協作池與算力池

  • 協作池負責尋找可協作的 AI／工作節點。
  • 算力池負責實際計算資源與任務派送。
  • 「看到協作池」不代表任務一定已經進入算力池；真正完成派送必須有任務建立、節點接收、執行與結果回傳。
  • 手機或其他裝置只有在使用者同意提供資源時，才應執行背景算力工作。

八、遇到問題怎麼處理

  1. 先重新整理頁面並確認網址。
  2. 如果是電子書：確認書籍是否能在書架看到，再確認閱讀模式是否能載入。
  3. 如果是暗星：確認是否能正常送出文字，再判斷語音／視訊是否為另一個獨立問題。
  4. 如果是算力：不要只看「尚未接入算力池」文字；應檢查任務是否建立、是否派送、是否有節點回報。
  5. 修復時採「只改故障模組」原則，不任意刪除已測試正常的功能。

九、重要原則

  • API 金鑰與服務密鑰只放後端，不放在公開前端。
  • 法律教材的 AI 解說必須能回溯到書名、頁碼與教材內容。
  • 正式法律研究應區分「法條原文」「學習性解讀」「學術觀點」與「AI 生成內容」。
  • AIVAULT 是多模組 AI 工作平台，不應把單一 Provider 當成 AIVAULT 本身。
