# AIVAULT 小模型職責與電子書證據式問答規格 v0.1
日期：2026-10-19
狀態：設計規格；未接入正式暗星、未部署、未執行付費 API。

## 原則
1. 暗星統一調度；模型按能力與已驗證狀態分派，絕不把 PLANNED/SIMULATED 當可用。
2. 書庫原文是可核對的來源，不是自動正確的結論。區分法條、作者觀點、學說、反對說及時間效力。
3. 能用 CPU、全文索引、規則完成的步驟不啟動 GPU。
4. 模型不允許虛構引文、書名、頁碼、法條或判決。證據不足時明確說明。
5. 書籍與使用者問題預設不外送 OpenRouter 或其他第三方模型。

## 任務分派
- EOT ONNX（已有權重）：語音句尾/輪次判斷；不處理法律語義。
- MobileNet V3 Small INT8（Storage 已有權重）：照片類別預分類；不負責文字 OCR 或法律答案。
- ANCN-ANN（隔離研發、未達生產標準）：未來候選段落排序；現階段回退 BM25/全文索引與規則排序。
- Qwen3-0.6B（外部開放權重，瀏覽器測試尚未確認）：未來意圖分類、查詢改寫、答案草稿；未載入時由規則路由，不得假裝成功。
- 檢索/證據驗證（確定性程式）：文本分段、書籍版本/頁碼對應、全文搜尋、逐字引文校驗、法域/日期校驗、缺證據阻斷。
- TTS（尚未證明自有權重可用）：僅在明確要求朗讀時調用，與答案真偽無關。
- OpenRouter（未部署）：不得作為電子書問答預設後備；外送書籍內容另需明確授權。

## 電子書問答管線
1. **存取權限**：由登入身分驗證可讀書籍，禁止跨使用者檢索。
2. **文本取得**：從現有電子書匯入與索引機制取得 TXT/PDF/EPUB 可提取文字；無法可靠提取時標示 BLOCKED，不猜測。
3. **可追溯切塊**：chunk_id、book_id、edition、chapter、source_page_label、source_offset_start/end、content_hash。PDF 影像頁或重排 EPUB 的頁碼不可靠時不得虛構。
4. **問題路由**：書名/作者/法域/時點/題型；優先精確詞與條文，再同義詞擴展。
5. **候選召回**：全文索引（可用時）與 BM25/詞項比對，保留前 N 筆；ANN 只有達成獨立評測門檻後才可作輔助排序。
6. **原文定位**：對每個候選做逐字對照、來源 hash 與偏移檢查，產生可回到電子書的定位符。
7. **回答**：先給有來源的命題；區分引用原文、合理推論與外部知識；模型僅在本地可用且授權時草擬。
8. **證據關卡**：每項關鍵結論須至少有一段可核對來源；頁碼、條號、引號文字逐一驗證；衝突來源並列而非任選。
9. **輸出**：結論、依據、書名版本、章節/頁碼或可定位段落、廣義/狹義觀點、反對意見、信心與限制。

## 回退與錯誤狀態
- BOOK_NOT_INDEXED：書在書架但尚未建索引。
- SOURCE_TEXT_UNAVAILABLE：PDF 掃描或加密導致無可靠文字。
- NO_EVIDENCE：沒有可核對的相關段落。
- CITATION_MISMATCH：引用無法對回原文；禁止作為已證實答案輸出。
- MODEL_UNAVAILABLE：本地語言模型或 ANN 不可用；使用檢索規則回退。
- JURISDICTION_AMBIGUOUS：繁體/簡體不能單獨決定法域；需結合條文、書籍及題幹。

## 驗收測試（必須在正式接入前執行）
- 書庫不存在的條文：不虛構內容。
- 同名不同版本：不混用頁碼。
- 廣義/狹義及不同學說：能分開標示來源。
- 錯誤 OCR：阻斷錯誤逐字引文。
- 私有書籍權限：跨帳號無法讀取。
- ANN/Qwen 不可用：檢索仍可運作，且清楚標示限制。
- 100 題具金標的法律/學術題：分別量測檢索 Recall@5、引文精確率、無根據主張率、答案正確率，不以自評代替。
- 每筆測試保存輸入版本、檢索證據、模型版本、錯誤原因，不記錄金鑰。

## 施工順序
A. 唯讀盤點既有電子書表、索引、RLS、匯入路由及暗星設定的電子書勾選路由。
B. 在隔離分支建立純 CPU 的文本切塊/檢索/引文校驗與測試，不改正式資料。
C. 以合法授權的測試書籍建小型金標集，完成離線驗證。
D. 逐步接入暗星電子書工具路由；僅經使用者授權才部署。
E. 最後再啟用通過評測的 ANN/Qwen；EOT、MobileNet、TTS 按情境調用。

## 禁止
未授權不得改正式暗星、曙光、因序，不得使用 Grok/Kling 額度，不得自行呼叫 OpenRouter，不得宣稱已完成端到端推理。
