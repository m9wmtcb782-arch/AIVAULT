# AIVAULT 角色語音 Worker 契約（施工分支）

## 現況
前端已具備 POST 請求與音訊檔頭驗證，但目前沒有已部署的 TTS 推論服務。24 個聲線 ID 只是角色規格，不能當成已訓練或已合成的 24 種聲音。

## Worker 介面
- 自架 HTTPS 端點：POST /synthesize
- 請求 JSON：schema_version=1、model="Qwen3-TTS"、voice_id、emotion、text
- 回應：HTTP 200；Content-Type 為實際音訊格式（建議 audio/wav）；body 為真實音訊位元組，不是 JSON 或假資料
- 失敗時：回傳非 2xx HTTP 狀態；不能回傳偽造的靜音檔並標示成功
- 瀏覽器跨網域：只允許正式授權的 AIVAULT 來源使用 CORS；不要使用萬用允許來源
- 不需要付費 API 金鑰；不要將任何服務角色金鑰寫進前端

## 必須完成的真實驗收
1. 自架 Worker 端實際載入可用的語音模型及模型權重。
2. 送出中文測試句並得到可解碼、可播放的音訊。
3. 記錄模型名稱、版本、推論裝置、處理時間、音訊秒數及輸出雜湊。
4. 分別驗證 24 個聲線 ID 對應到模型實際支持的不同音色；若模型無法區分，必須標示 UNSUPPORTED，不得複製同一段聲音冒充。
5. 驗證兒童、成人、老年及男女聲線的辨識度、自然度與中文準確性。
6. 未驗證前維持 NOT_DEPLOYED，禁止標示 PRODUCTION_READY。

## 已知限制
前端的音訊格式檢查僅驗證基本容器標頭，無法證明音訊內容正確、聲線不同或模型真的推論。自架 Worker 的部署位置、資源、模型權重與 24 聲線映射仍待確認。
