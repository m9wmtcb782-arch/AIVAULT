# Free-only resource pool

Status: design only. Not deployed.

- Allow only verified free model inference resources.
- Never use paid plans, paid trials, credit cards, or automatic billing.
- Do not register multiple accounts to bypass quotas.
- Require authorization and compliance with platform registration rules.
- Unknown terms or price: block.
- Protect existing AI gateway, paid gate, voice, video and memory.
- Centralize quota allocation across agents; agents do not each get a separate free quota.
- No external API calls or account registrations during development without separate approval.
