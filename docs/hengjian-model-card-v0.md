# 衡鑑 AI 模型卡 v1.1（Prototype）

**模型名稱：** HENGJIAN-PROTOTYPE-v1.1  
**版本：** 0.2.1-browser  
**日期：** 2026-11-27  
**狀態：** 原型修正（未微調、未經專業評測）  
**屬於：** AIVAULT 第一基地 · 第二階段可執行原型

## 基底模型
- **候選：** Qwen2.5-1.5B-Instruct-q4f16_1-MLC（WebLLM 預建）
- **參數：** ~1.5B
- **量化：** 4-bit
- **授權：** Apache 2.0（基底）
- **運行環境：** 瀏覽器 WebGPU

## 網路與外部依賴盤點
- **CDN / 庫：** `https://esm.run/@mlc-ai/web-llm`（首次載入 JS 模組）
- **模型權重：** 由 WebLLM 從 MLC / Hugging Face 等來源下載（約 800MB–1.1GB）
- **首次下載：** 必須有網路
- **下載後：** 瀏覽器快取可用於後續離線推理
- **非完全離線可啟動。** 無付費 API、無外部 AI 推理服務（推理在本地 WebGPU）

## 硬體需求（估計）
- VRAM / 統一記憶體：~1.5–2 GB
- 瀏覽器：Chrome / Edge 支援 WebGPU

## 能力範圍（原型 v1.1）
- 接收模擬參數
- 內嵌合成知識庫：明確主題關鍵字對照（7 部法示範條文），無匹配時明確顯示「未找到」，不虛構
- 顯示命中原因、法規名稱、條文、來源
- 輸出：風險摘要、可能法規參考、不確定事項、改善建議框架
- 格式檢查日誌（非專業正確性評測）：格式完整性、法規引用是否來自實際檢索、不確定性揭露、建議具體性、人工覆核狀態（預設「待覆核」）

## 安全與限制
- 資料不離開瀏覽器
- 無外部 AI 推理服務
- 失敗時明確標示
- 禁止使用於正式決策

**不得宣稱已達專業審計標準或政府採用。**
